# LookForwardCalendar（LFCalendar）v1.3.0

![LookForward logo](docs/logo.png)

> 日历页上升起的太阳，和日期格里高亮的那一天：期待接下来的每一天。同一份像素数据也用作 exe 图标；程序内按 `v` 可以看到终端版。

LookForwardCalendar（简称 LFCalendar）是基于 [FTXUI](https://github.com/ArthurSonzogni/FTXUI) 的终端日历程序（Windows）。月视图日历，支持农历与节气、中国/日本节假日、带提醒的日程事件，以及按工作日自动分配工作量的长期任务。

## 功能一览

- **月视图**：每周从周日开始（日 一 … 六），显示农历、农历节日、二十四节气、节假日（休/班）
- **瞬间型事件**：某天某个时段的日程，可设置提前提醒
- **固定日程**：按周期重复的工作内容和时间段（默认每周），如每周二、四的组会
- **长期任务**：设定总时长和截止日期，程序把剩余工作量平均分配到每个工作日；每天记录实际进行情况，后续安排自动调整
- **节假日**：通过 AI 获取指定国家、年份的节假日，导入为本地数据
- **任务总览、提醒列表**：整屏子界面

## 编译与运行

需要：GCC 13 及以上（支持 C++23）、CMake 3.20 及以上、Ninja、Git，以及首次编译时的网络连接（用于下载 FTXUI 和 nlohmann/json）。

```bash
./build.sh          # 配置 + 编译 + 运行单元测试
./build.sh run      # 同上，然后在新的控制台窗口中启动程序
./build.sh clean    # 删除 build/ 后重新编译
```

编译结果为 `build/LookForward.exe`。

- 请在 **Windows Terminal、PowerShell 或 cmd** 中运行。Git Bash 的终端无法正常接收按键，所以 `./build.sh run` 会另外打开一个窗口。
- 建议窗口宽度在 **120 列以上**。
- 编译器路径写在 `CMakePresets.json` 中，换电脑时请按实际情况修改。

## 界面

```
┌ 月历 ─────────────────────────────┐┌ 侧边栏（选中日期）─────┐
│ 日  一  二  三  四  五  六          ││ 农历、节假日           │
│ 3今                                 ││ 【事件】  [改][删]     │
│ 廿五     ← 农历/节日/节气           ││ 【任务】               │
│ ●1 ▶3:40 ← 事件数 / 工时            ││ 任务名                 │
│                                     ││ (ID:xxxx)       进行中 │
│                                     ││  计划 2:40 实际 1:30   │
│                                     ││ [进行][暂停][修改]…    │
└─────────────────────────────────────┘└────────────────────────┘
 快捷键提示（移动 / 功能 / 配置 三行）       ⏰ 提醒 N 条（m 查看）
```

月历格子第三行的含义：`●n` 表示当天有 n 个事件；`◆n` 表示当天有 n 个固定日程；`▶h:mm` 表示今天及以后的计划工时；`✓h:mm` 表示过去日期的实际工时；红色 `!` 表示有超期任务。

## 瞬间型事件与提醒

在月历上按 `a`，或在侧边栏按「+ 新建事件」，填写标题、开始和结束时间（可空，格式为 `HH:MM`）、备注。

勾选「提醒」并填写提前量，可以写成 `30m`（30 分钟）、`1:30`（1 小时 30 分钟）、`2`（2 小时）或 `1d`（1 天），最长 30 天。

- 提醒期间从“开始时间 − 提前量”开始，到事件结束为止；没有结束时间的事件，到开始的那一分钟为止。
- 全天事件（不填时间）以当天 0:00 作为开始时间，提醒持续到当天结束。
- 处于提醒期间的事件会出现在提醒列表（`m`）中，按发生时间排序。程序每 30 秒自动刷新一次。

## 固定日程

按周期重复的工作内容和时间段，适合组会、课程、例行工作等。在月历上按 `f`，或在侧边栏按「+ 新建固定日程」，填写：

| 项目 | 说明 |
|---|---|
| 工作内容 | 必填 |
| 开始时间 / 结束时间 | 必填，格式为 `HH:MM` |
| 重复 | 每天 / 每周（默认）/ 每两周 / 每月 |
| 星期 | 每周、每两周时勾选哪几天，默认为开始日期是星期几 |
| 开始日期 | 默认为选中的日期 |
| 结束日期 | 可空，空表示一直重复 |
| 备注 | 可空 |

- 每两周：从开始日期所在的那一周算起，隔一周一次。
- 每月：在开始日期的那一天重复；没有这一天的月份（如 31 日）跳过。
- 月历切换到某个月时，才计算这个月里哪些天有固定日程。
- 侧边栏中每个固定日程显示时间段、工作内容、重复方式和备注。`[删]` 会删除这个固定日程的所有日期，所以要按两次：第一次变为 `[确认删除]`，再按一次才删除。

## 长期任务

按 `n` 新建任务，需要填写：

| 项目 | 说明 |
|---|---|
| 任务名 | 必填 |
| 预定时长 | 小时数，如 `40` 或 `12:30` |
| 完成日期 | `YYYY-MM-DD` |
| 每周工作 | 勾选每周哪几天工作 |
| 跳过节假日 | 勾选后，放假日不分配工作量 |
| 节假日国家 | 跳过节假日时依据的国家 |

每个任务有一个随机生成的 ID（如 `ID:a3f9`），侧边栏中每个任务的第一行是任务名，第二行是 ID 和任务状态，任务之间空一行。内容超出一屏时右侧出现滚动条，用方向键或鼠标滚轮滚动。在任务总览中按 `Enter` 可以查看任务的全部日志，按 `d` 可以删除任务（会删除任务文件，无法恢复）。

**工作量分配规则**

- 剩余量 = 预定时长 − 今天之前实际完成的时长。把剩余量依次平均分给从今天到截止日期之间的每个工作日，每天向上取整到 10 分钟。
- 创建当天也算作一个工作日。
- 今天的计划只按今天之前的实际时长计算，所以今天记录的工作量不会改变今天的目标，只影响以后的安排。
- 某天没有记录，就按 0 计算，之后几天的量会自动增加。
- 超过截止日期仍未完成的任务会标红，并视为暂停；修改截止日期后自动恢复。

**侧边栏中的任务按钮**（排在每个任务的最后一行，从左到右）

| 按钮 | 作用 |
|---|---|
| `[进行]` | 填写当天的实际时长和进行内容，可以反复修改。未来日期锁定，不能填写 |
| `[暂停]` / `[恢复]` | 暂停期间不分配工作量，截止日期不变 |
| `[修改]` | 修改时长、截止日期、工作日等，后续安排自动重新计算 |
| `[中止]` / `[完成]` | 结束任务 |

新建或修改跳过节假日的任务时，如果从今天到截止日期之间有年份还没有导入节假日数据，会取消这次操作，并提示先导入。

## 导入节假日

1. 按 `i`，选择国家和年份，按「生成并复制提示词」，提示词会自动复制到剪贴板。
2. 把提示词粘贴给任意 AI（如 Claude）。AI 会把 JSON 放在代码块中返回；能生成文件的 AI 还会同时给出 `<国家>_<年>.json`，直接下载即可，否则把代码块内容保存成文件（连同代码块前后的文字一起保存也没关系）。
3. 在「文件路径」中填入这个文件的路径（带引号的路径也可以），按「导入」。

程序会检查格式，以及国家、年份是否和所选的一致。检查通过后保存到 `data/holidays/<国家>_<年>.json`；同一国家同一年份的旧数据会被整体覆盖。

## 数据文件

数据保存在 exe 所在目录下的 `data/` 中，也可以用 `LookForward.exe --data <目录>` 指定其他位置。全部是 UTF-8 编码的 JSON 文件，可以直接用文本编辑器查看或修改；改完后在程序里按 `r` 刷新。

```
data/
  general/<年>/<月>.json        每天的事件，如 general/2026/11.json
  task/<创建日期>_<ID>.json     每个任务一个文件，内容是操作日志
  fixed/<创建日期>_<ID>.json    每个固定日程一个文件
  preference.json               配置：当前的国家和语言，启动时读取
  holidays/<国家>_<年>.json     导入的节假日，如 holidays/CN_2027.json
```

任务文件按日志方式记录每一次操作：创建、修改、进行、暂停、恢复、完成、中止，以及每次操作的时间。
